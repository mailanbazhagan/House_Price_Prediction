# Linear Regression: Train, Save and Deploy

A beginner-friendly end-to-end classroom project using synthetic house-price data.

## Files
- `train_model.py`: creates data, trains/evaluates Linear Regression, saves the pipeline.
- `app.py`: Streamlit interface that loads the saved model and predicts a price.
- `requirements.txt`: dependencies.
- `model.joblib` and `metrics.txt`: generated by the training script.

## 1. Create a virtual environment

Windows PowerShell:
```powershell
python -m venv ml_env
.\ml_env\Scripts\Activate.ps1
```

Windows CMD:
```cmd
python -m venv ml_env
ml_env\Scripts\activate.bat
```

macOS/Linux:
```bash
python3 -m venv ml_env
source ml_env/bin/activate
```

## 2. Install dependencies
```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## 3. Train and save the model
```bash
python train_model.py
```
This creates `model.joblib` and `metrics.txt`.

## 4. Test locally
```bash
streamlit run app.py
```
Open the local URL shown in the terminal (usually http://localhost:8501).

## 5. Push to GitHub
Create a public GitHub repository, then run these commands in this folder:
```bash
git init
git add .
git commit -m "Add house price prediction app"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```
Replace the URL with your own repository URL. Run the training script first so `model.joblib` exists and is included in the repository.

## 6. Deploy on Streamlit Community Cloud
1. Sign in to Streamlit Community Cloud with GitHub.
2. Select **Create app**.
3. Choose your repository, branch `main`, and main file `app.py`.
4. Deploy and wait for the app to build.
5. Open the public URL provided by Streamlit.

## Teaching points
- The saved artifact is the complete scikit-learn pipeline, including `StandardScaler`.
- The app supplies the same three feature names used during training.
- Train before running or deploying the app.
- This is synthetic classroom data, not a source of real property valuations.
- Never commit passwords, API keys, or private student data.
